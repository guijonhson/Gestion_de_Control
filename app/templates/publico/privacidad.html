Política de Privacidad

Última actualización: borrador sin fecha definitiva.

1. Responsable

AgroDev PTY, {{ contacto.pais }}. Contacto: {{ contacto.correo }} · {{ contacto.telefono }}.

2. Datos que se recogen

  • Datos de la cuenta: nombre del productor, teléfono, correo, nombre de usuario y contraseña cifrada.
  • Datos agropecuarios que el usuario registra: fincas, parcelas, cultivos, aplicadores, inventario, gastos, producción y registros de aplicación.
  • Fecha de aceptación de estos documentos y fecha del último acceso.

3. Para qué se usan

Para prestar el servicio, mostrar la información al usuario que la registró, gestionar el plan contratado y contactar al usuario cuando solicita soporte o recuperación de contraseña. No se venden datos a terceros.

4. Dónde se guardan

La información se guarda en servicios de infraestructura en la nube usados por AgroDev PTY para alojar la aplicación y la base de datos. El acceso público a la base de datos está restringido; la aplicación se conecta mediante credenciales privadas.

5. Conservación y eliminación

Los datos se conservan mientras la cuenta esté activa. El administrador puede eliminar usuarios y su historial desde el panel de gestión. Para solicitar la eliminación de datos, escribe a {{ contacto.correo }}.

6. Seguridad

Las contraseñas se almacenan cifradas. El acceso a los datos requiere iniciar sesión y cada productor solo puede consultar su propia información. No se debe compartir la contraseña.

7. Servicios de terceros

La aplicación usa servicios de alojamiento y base de datos en la nube, y un servicio de envío de alertas por correo al administrador. No se usan redes sociales ni servicios de análisis publicitario.

8. Cambios

Estos textos pueden actualizarse. La versión vigente estará publicada en esta misma página.
