Términos y Condiciones

Última actualización: borrador sin fecha definitiva.

1. Servicio

Gestión de Control es una aplicación web de AgroDev PTY para registrar y consultar información agropecuaria: fincas, parcelas, cultivos, aplicadores, inventario, gastos, producción y registros de aplicación.

2. Cuenta y acceso

Para usar el sistema debes crear una cuenta con datos veraces y mantener la confidencialidad de tu contraseña. Eres responsable de la actividad realizada con tu cuenta. El administrador puede suspender cuentas por uso indebido.

3. Planes y límites

Los precios y límites vigentes se muestran en la página de planes y se leen de la base de datos del sistema. Los pagos se coordinan por los canales de contacto oficiales. No se procesan pagos automáticos dentro de la aplicación.

4. Uso permitido

No debes intentar acceder a datos de otros productores, alterar el funcionamiento del sistema, introducir código malicioso ni usar la aplicación para fines distintos a la gestión agropecuaria.

5. Datos del usuario

La información que registras pertenece a tu actividad. AgroDev PTY la usa para prestar el servicio y contactarte. El tratamiento de datos se describe en la Política de Privacidad.

6. Disponibilidad

El servicio se ofrece tal como está disponible. Puede haber interrupciones por mantenimiento, fallos de internet o de los proveedores de infraestructura. La aplicación necesita conexión a internet para funcionar; la versión instalable no permite editar datos sin conexión.
